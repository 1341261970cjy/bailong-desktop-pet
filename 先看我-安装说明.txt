白龙桌宠定制更新版 — 使用与安装说明

项目：https://github.com/1341261970cjy/bailong-desktop-pet
完整使用说明：使用说明.md；开发和构建说明：DEVELOPMENT.md。

一、源码与完整程序包
本次Git提交更新的是基于v0.5.1 WebM的定制源码，尚未在本仓库发布新的定制版GitHub Release。
GitHub“Code → Download ZIP”是源码，不是可直接双击运行的程序。原作者v0.5.1旧EXE不包含本次后续修改。
若拿到单独构建的完整Windows包，请先全部解压，再双击BailongPet.exe。不能只复制EXE；_internal、outputs、tools及配套app目录需要一同保留。完整包无需另装Python。
首次启动会预加载动画，需要等待片刻。更新本地程序前退出旧桌宠。移动程序文件夹前先关闭自动启动，移动后再重新开启。

二、运行当前源码
验证环境：Windows x64、Python 3.12.14。
在项目目录执行：
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
从上游完整v0.5.1 WebM发布包复制整个outputs和tools文件夹到项目根目录，与app并列：
https://github.com/jingh12312-rgb/bailong-desktop-pet/releases/tag/v0.5.1
需要全部动画、素材清单与tools/ffmpeg.exe；这些大文件不在Git源码中。
启动：.venv\Scripts\python.exe app\pet.py
离线自检：.venv\Scripts\python.exe app\pet.py --self-test

三、基本操作与界面
鼠标悬停出现“聊天 / 额度 / 声音 / ⋯”。“⋯”与右键桌宠均可打开更多设置。
单击互动，双击查询额度；按住左键拖动移动，靠近屏幕边缘可吸边，菜单可展开桌宠。
右键可调节桌宠大小、提示大小、自动移动、全屏自动隐藏，以及隐藏/显示桌宠。隐藏后可通过系统托盘恢复；“退出桌宠”关闭程序。
额度面板使用紧凑布局和更大的主要文字，金额保留三位小数，不显示更新时间。标题右侧的圆圈用于刷新，查询时转动，不另占一行提示。最近调用显示日志中的首字等待和总耗时约值，以秒为单位。
额度保留当前左侧或右侧，只有该侧放不下时才换边；互动提示先定位再显示，工作汇报靠近桌宠头侧，减少遮挡、跳位和多余留白。
悬停按钮跟随桌宠移动，贴近屏幕底部时会避开角色。
完成汇报短内容约15秒、长内容约30秒后自动收起；进展提示在最后更新约15秒后收起。完整结果仍可从聊天历史或详情查看。

四、聊天与任务
聊天、Codex官方额度及任务同步需要自己的Codex安装、登录与网络。普通动画、移动和吸边不依赖账号。
点击“聊天”使用简易输入框；Ctrl+Enter发送，Enter换行。“文件夹”选择任务目录，“历史”打开完整聊天窗口，“+ 新建”开启新会话。
完整窗口为紫白圆角界面，右上角可最小化、最大化/还原、关闭；顶部可拖动，右下角可缩放。
执行中可停止任务。公开进展、异常和完成结果分别提示；任务成功播放一次庆祝动画，不再额外播放点击声。
右键“对话框大小…”可关闭任务气泡提醒，不影响额度卡片。对话历史保存在本机，不随Git公开。
从桌宠发送任务会正常消耗自己的Codex额度。

五、DogAPI钱包与今日消耗
右键“中转站设置…”，地址填写https://www.dogapi.cc。
钱包余额：填写模型调用API Key（通常以sk-开头）。
完整今日消耗：另外填写网站用户Access Token与数字账号ID。普通模型API Key不能代替账单访问令牌。
账号ID在网站个人资料姓名旁的User ID复制；用户令牌在Profile（个人资料）→Security（安全）→Access Token获取。
注意：该网站打开Access Token项会重新生成并复制令牌，可能使旧用户令牌失效，请手动确认这一影响后操作。
今日消耗按北京时间当天00:00至查询时刻，读取日志完整统计接口。普通Key的最近1000条日志不足以保证覆盖全天，程序不会用累计或截断金额冒充今日总额。
未配置账单权限或统计失败时会提示；钱包可单独显示。金额保留三位小数，DogAPI开启时每分钟刷新，也可点击“额度”手动刷新。
Codex与DogAPI卡片可在右键菜单分别开关。
所有凭据只填写到本机设置中，不要写入源码或上传GitHub；留空保留已保存值，勾选清除选项可移除。

六、声音
公开源码只提供原点击声；个人导入的爱给网小黄鸭和其他私人音频不上传Git。需要其他声音可自行导入本地文件。
点击“声音 → 添加或更换本地音效…”，支持WAV、MP3、OGG、FLAC；可试听或静音。
每次点击只播放文件一遍；若文件本身包含重复片段，一次播放仍会播放该文件的完整内容。
Windows导入音频保存到D:\CodexDragonBuild\UserData\sounds。D盘不可用会提示失败；需保留tools/ffmpeg.exe用于转换。

七、检查与平台说明
完整包可运行“检查桌宠.cmd”或BailongPet.exe --self-test；离线检查通过不代表已配置网站今日统计权限。
如果钱包可用而今日消耗无权限，核对网站用户Access Token和数字账号ID，再保存并刷新。
如果缺少素材、解码器或TLS运行文件，重新核对完整目录与开发构建说明。不要把运行报告、聊天记录、密钥、个人音频提交到公开仓库。
当前主要验证Windows x64。macOS适配源码尚未完成实机验收，不提供已验证Mac包；Linux、32位Windows与Windows ARM未验证。
